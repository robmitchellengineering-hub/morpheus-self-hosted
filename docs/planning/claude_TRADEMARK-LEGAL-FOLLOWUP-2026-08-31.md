## What's already been surfaced (not verified/actioned — informational only, not legal advice)
- A web search found multiple **existing US trademark registrations** for "Morpheus," including:
  - **Morpheus Data, LLC** (registered 2015) — general software/data platform, closest to Morpheus's own space.
  - **Morpheus XR** — AR/software platform.
  - Others in gaming (Everi Games) and music tech (Rossum Electro-Music).
- These are US registrations only — trademarks are territorial, so they don't automatically block use in Australia or NZ, but they signal "Morpheus" is a heavily-used name in software/tech generally.
- No Australia (IP Australia) or New Zealand (IPONZ) specific search has been run yet.

3. Does the Pty Ltd structure adequately shield Rob personally from liability as currently set up — worth confirming with an accountant/lawyer rather than assuming.
4. Terms of Service / liability disclaimers for the Morpheus product itself — not yet drafted.
