The Morpheus WordPress Plugin

What it is, what it lets you do, why it matters to the WordPress market — and what running a WordPress site costs with it versus without it.

Prepared 15 October 2026 · Plugin version 0.9.13 · Figures are indicative market ranges from the cited sources, not quotes.

One paragraph summary

The Morpheus plugin turns an ordinary WordPress site into something an AI operator can work on — deploy code, run a store, own the SEO, watch traffic, redirect dead links, and fix what is wrong — through a signed, audited channel from a phone, without ever handing over a WordPress password or an FTP login. The plugin itself is free and open (GPL). It is the hands on the site; the Morpheus platform (morpheus.nz) is the brain that drives it, billed by what you actually use rather than a monthly retainer.

What it is

Morpheus is a self-hosted AI platform that builds and operates software. Its WordPress plugin is the site-side half of that system — a single, free WordPress plugin that connects a site to the Morpheus app. Its only admin surface on the site is a small Settings screen (the pairing code and the dock switch); the working panels live in the Morpheus app and the dock. Everything it does is reached through a signed REST API, which is how the platform asks it to act.

How the connection is secured

  • No passwords, no FTP. Pairing is a one-time code shown in Settings → Morpheus (valid 20 minutes, usable once). The plugin generates the shared secret itself — nothing is invented, copied or retyped by hand.
  • Every request is signed. Morpheus sends an HMAC-SHA256 signature over the raw request body in an X-Morpheus-Signature header, with a timestamp that must be inside a five-minute window — so a request can neither be forged nor replayed.
  • The secret lives in one place and is encrypted at rest on the Morpheus side; the site only ever stores its own half.

Everything the plugin can do is reached at /wp-json/morpheus/v1/<module> — Deploy, Store, SEO, Traffic, Redirects, Health, Clean, Maintenance, Fix, Updates, Pairing, Export and Dock. Each module is a separate, deliberately narrow surface.

What it lets you do

Deploy — ship code without touching a server

Connect the GitHub repository your theme lives in. Morpheus opens a pull request; once the checks pass and it merges, the plugin applies exactly the files that commit changed — snapshots what it touches, health-checks the live site, and rolls the snapshot back if anything breaks. A hard deny-list (wp-config.php, uploads, cache, .git, .htaccess, .env) is enforced regardless. Writing is gated behind an explicit "Armed" switch.

Store — run the shop from a phone

Create products, set stock and prices, and draft posts and pages over the signed API. WooCommerce is used when present; plain pages and posts work without it.

SEO — own every field, with or without another plugin

Read and write title, meta description, focus keyword, canonical, social image and noindex for any page, post or product; list content; read a page's real text so generated copy is grounded in it; and audit for real problems. With no third-party SEO plugin, Morpheus emits the tags itself. With Yoast, Rank Math, AIOSEO or SEOPress active, it drives that plugin's fields instead — two plugins never emit competing <title>/description tags. Site-wide title/description templates and one-click internal-link proposals fill the gaps.

Traffic — tell search engines, and prove it

Submits new and changed URLs to IndexNow on publish (covering Bing and Yandex, with no account or third-party key), and keeps a submission ledger showing the HTTP status each URL actually received — a record, not a claim.

Redirects — no more dead links

Keeps a 301/302/307/410 rule list applied before the theme loads, plus a 404 log grouped by path so a thousand hits on one retired product URL shows as one row with a count. wp-admin, login, the REST API and cron are never redirectable.

Health — what is wrong, and what fixes it

Runs WordPress's own Site Health tests (plus WooCommerce's) and reports the results, what can be updated, and whether files can be written at all. The six async tests it cannot run are reported as "not run, and here is why" — never silently omitted. Deliberately no score: findings are ordered worst-first and counted, with their source kept separate.

Clean My Site — what is on the server that nobody asked for

Checksums every WordPress core file against wordpress.org, inventories uploads and mu-plugins, flags any .php under uploads, lists admin accounts and unattributed cron jobs, and finds a publicly readable debug.log or stray wp-config.php.bak. Nothing is ever deleted — files are renamed to a timestamped backup, re-checked, and put straight back if the site does not confirm.

Maintenance — safe, reversible updates

Reports what could be updated and applies plugin, theme and minor core updates one at a time, each zipped to a backup, verified afterwards and restored on failure. A major WordPress version update is never automatic — it is reported for a human.

AI Fix — a change you read before it happens

For a finding with no automatic fix, Morpheus proposes the exact change in plain words and changes nothing until you press apply. The model can only choose from operations that already exist in the plugin, and every argument is checked against the site's own state first; anything else is a refusal that names itself.

Updates, Pairing, Export and Dock

Registers WordPress's own update channel and verifies each download against a published SHA-256 (a package that cannot be verified is refused, not installed). Pairs with a one-time code. Hands the active theme over as a text-only working copy so a site not yet in git gets the full pipeline. And prints the floating Morpheus button on the site's pages for a signed-in administrator only — the token it carries acts as the owner, so a visitor or editor never receives it.

Why it matters to the WordPress market

WordPress runs roughly 43% of all websites — hundreds of millions of sites, and a clear majority of the sites that use any CMS at all. That scale comes from being open and self-hosted, which means the day-to-day burden of operating a site — updates, backups, security, monitoring, changes — lands on the individual owner. It is a genuine ops job, and most owners are not ops engineers.

That gap is why an entire "care plan" industry exists: agencies and freelancers charging $100–$500 a month per site to do the routine maintenance nobody should have to think about. The ecosystem's answers so far have all been human-shaped — hire someone, or buy a monitoring dashboard that still needs a human to read it and click.

The Morpheus plugin changes the shape of that answer:

  • From watching to doing. Management dashboards (ManageWP, MainWP, WP Umbrella and similar) mostly observe and batch — a human still decides and acts. Morpheus acts on the site through the signed API, with verify-and-rollback rails so a bad change does not stick.
  • From desktop to phone. Deploy, store, SEO and fixes are reachable from a phone, over a signed channel, with no credential sharing.
  • From a bill that starts on day one to a meter. There is no fixed retainer and no per-site headcount cost; you pay for the work the platform actually does.
  • From "an error someone will explain" to a verifiable record. Every write is signed, snapshotted, checked against the live site, and recorded — the ledgers, logs and refusal records are the evidence, not a summary of it.

The significance is not "another SEO plugin." It is that the largest content platform on the web can now be operated by an AI over an audited interface, with the safety rails a professional would insist on — which is precisely the part of WordPress ownership that has, until now, been stuck in the hire-a-human era.

Reading Morpheus's pricing honestly

  • The plugin is free (GPL) and installs in one step — there is no licence to buy for the WordPress side.
  • Morpheus bills in credits: $5 per 1,000 credits, sold in small packs ($2 / $4 / $8 → 400 / 800 / 1,600 credits) with a 200-credit free grant on signup.
  • It is usage-priced, not a retainer: a quiet month costs less than a busy one, and there is no bill that starts before you have used anything. The honest caveat is the mirror image of that — unlike a care plan, there is no fixed monthly ceiling, so a very busy month costs more.
Boundary worth stating plainly: Morpheus addresses the operating side of WordPress — deployment, store, SEO, traffic, health, security and maintenance. A genuinely bespoke design or build (a custom theme from scratch, a complex integration) may still want a human. The comparison is against the recurring maintenance-and-change bucket that most site owners pay for every month, not against one-off build work.

The bottom line

For a site owner today, "manage my WordPress" almost always means a recurring bill to a person or a company, or quietly absorbing the ops work yourself. The Morpheus plugin offers a third shape: keep your site where it is, install one free plugin, and let an AI operator do the routine work over a signed, verifiable channel — paying for the work it actually does rather than a retainer that recurs whether you needed it or not. That is the significance: the world's most common website is now operable by software, on rails a professional would trust.
